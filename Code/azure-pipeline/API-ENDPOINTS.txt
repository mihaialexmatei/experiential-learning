ENDPOINTS
---------

1. POST /audio-to-image?code={FUNCTION_KEY}
   - Send: Audio WAV bytes in body
   - Returns: PNG image + X-Category header (beach/mountain/forest/garden)
   - Use: Main pipeline - audio to panorama image
   
2. GET /sounds/{category}
   - Categories: beach, mountain, forest, garden
   - Returns: Random MP3 ambient sound
   - Use: Get sound after getting category from audio-to-image
   - Example: /sounds/mountain
   - No auth needed

3. GET /images/{category}
   - Categories: beach, mountain, forest, garden
   - Returns: Random pre-made panorama PNG
   - Use: Get pre-generated images
   - Example: /images/beach
   - No auth needed

UNITY FLOW
----------
1. POST audio to /audio-to-image
2. Read X-Category from response header
3. GET /sounds/{category} to get matching sound
4. Apply image to skybox + play sound
